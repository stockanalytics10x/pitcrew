# 피트크루 (PitCrew)

> 내 차의 주행 기록으로 언제·어디서 충전·주유·정비·세차할지 먼저 알려 주는 차량용 피트 크루 앱

Pleos Connect(AAOS) 차량에서 동작하는 Kotlin / Jetpack Compose 앱입니다.

## 핵심 기능

| 기능 | 하는 일 |
|---|---|
| **피트월 판단 엔진** | 목적지까지 도착 잔량을 이 차의 학습된 전비(km/%)로 계산해 완주 가능 / 피트인 권장 / 피트인 필수를 판정하고, 주행 중 Box 콜(음성)로 알려 줍니다. |
| **피트 플래너** | 지난 주행 기록(요일별 거리·날씨별 효율)을 500번 다시 굴려 다음 충전·주유가 필요한 날과 세차하기 좋은 날을 예보합니다. |
| **크루 체크 · 피트 파인더** | 경고등·타이어 공기압 등 차량 신호를 정리하고, 공공데이터(세차장·정비소·휴게소·충전소·주유소)에서 할 일에 맞는 장소를 찾아 내비로 안내합니다. 운전자가 확인한 장소는 크루 리포트로 쌓입니다. |

받쳐 주는 기능: 충전 중 자동 감지 화면, 주행 데이터·리포트, 시연 모드, 설정(권한·음성).

데이터 구분: 화면의 값은 **차량 값 / 추정 / 시연 / 미지원**으로 구분해 표시하며, 받지 않은 가격·점수·경로를 만들어 보여 주지 않습니다.

## 실행 방법

1. Android Studio(최신 안정판)에서 이 폴더를 엽니다.
2. 프로젝트 루트의 `local.properties`에 공공데이터 API 키를 넣습니다. 키가 없어도 앱은 실행되며, 해당 데이터만 비어 있습니다.
   ```
   EV_CHARGER_KEY=발급받은키      # 한국환경공단 전기자동차 충전소 정보 (공공데이터포털)
   OPINET_KEY=발급받은키          # 한국석유공사 오피넷 유가정보
   ```
   따옴표 없이 적습니다. 이 파일은 저장소에 올라가지 않습니다.
   날씨(기상청 단기예보)는 팀 중계 서버를 거쳐 받아서 따로 키가 필요 없습니다.
3. Pleos Connect 에뮬레이터를 실행하고 ▶ Run 합니다.
4. 처음 실행하면 마이크·위치·차량 권한을 허용합니다. 설정(⚙)에서 다시 요청할 수 있습니다.
5. 차량 신호 없이 흐름을 보려면 설정의 **시연 모드**를 켭니다.

빌드(명령줄):
```
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

## 테스트 환경

| 항목 | 값 |
|---|---|
| 에뮬레이터 | Pleos Connect v2.1.0 (Android 14, API 34, x86_64, android-automotive) |
| AVD 설정 | RAM 4GB · Graphics Hardware(`hw.gpu.mode=host`) · Cold boot |
| 화면 | 2560×1440 px, 160 dpi (앱 영역은 오른쪽 약 1682×1210 px, 왼쪽은 주행 뷰) · 1280dp 폭 기준으로 설계해 작은 창은 비율대로 축소 |
| Pleos SDK | Vehicle 2.3.2, NaviHelper 3.0.5, FusedLocation 1.1.3, TextToSpeech 3.3.1, SpeechToText 3.3.1 |
| minSdk / targetSdk | 28 / 37 |
| 단위 테스트 | 182개 (`app/src/test`) |

에뮬레이터에서 확인한 것과 실차에서 확인이 필요한 것은 구분합니다. 세차 모드(창문·공조 제어)는 실제 차량 쓰기 동작이 있어 실차 재검증이 필요합니다.

## APK

- 위치: [`apk/BoxBox_PitCrew_release.apk`](apk/BoxBox_PitCrew_release.apk) (release 빌드, 서명됨, 약 29MB)
- 지원 ABI: arm64-v8a(실차), x86_64(에뮬레이터)
- 설치: 에뮬레이터 창에 APK를 끌어다 놓거나
  ```
  adb install -r apk/BoxBox_PitCrew_release.apk
  ```
- 설치 후 설정(⚙)에서 **경고등 정보**·**차량 속도**·**차량 위치**·**마이크** 권한을 허용합니다.
- 차량 신호는 Virtual Console(`adb forward tcp:8088 tcp:8088` → http://127.0.0.1:8088)로 바꿀 수 있습니다.

### 에뮬레이터에서 확인할 때

- 에뮬레이터는 **Cold boot**로 켭니다. Quick boot면 차량 신호(VHAL)가 오지 않을 수 있습니다. 다시 켜면 `adb forward tcp:8088 tcp:8088`도 다시 실행하고, 배터리·주행 가능 거리는 Virtual Console에서 한 번 바꿔 주면 앱으로 전달됩니다(값이 바뀔 때 전달).
- **주행 중 화면**: Pleos Connect 에뮬레이터는 기어 D에서 외부 설치 앱 화면을 시스템이 가립니다(“주행 중에는 사용할 수 없습니다”). 앱은 기어 D를 정상으로 인식하며, 주행 화면·Box 콜 흐름은 설정(⚙)의 **시연 모드**로 확인할 수 있습니다.
- **크루 체크(정비)**: 설정(⚙)에서 **경고등 정보** 권한(`PRIVATE_CAR_SAFETY`)을 허용하면 Virtual Console의 경고등(TPMS 등)을 받아 분류합니다. 엔진오일·브레이크액·워셔액은 에뮬레이터가 제공하지 않아 해당 부위는 “? 신호 대기”로 표시합니다. 앱은 받지 않은 값을 “이상 없음”으로 표시하지 않습니다. 타이어 공기압 경고 → 정비소 안내 흐름은 **시연 모드**에도 들어 있습니다(화면에 “시연” 표시).
- 시연 모드의 값은 실제 차량 값과 구분해 표시하며, 주행 기록 DB에는 저장하지 않습니다.
